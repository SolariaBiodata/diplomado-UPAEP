# Comando *htop* 
Este comando es un visor para gestionar los procesos del sistema en texto y tiempo real. En sistemas Linux viene este visor, pero en el caso contrario es necesario instalarlo a través de los administradores de tapetes. La sintaxis correcta de este comando es:
~~~
R4ndi@SEQ:~$    htop
~~~
