# Comando *uname* 
El comando *uname* despliega información sobre el sistema Linux, nombre del host, arquitectura del hardware y sistema operativo junto con la información de la máquina y números de versión. También puede detallar aún más profundo con las siguientes opciones:
## Información completa \(*-a*\) 
Esta opción permite detallar toda la información completa del sistema. Por ejemplo:
~~~
uname -a
Linux hostname 4.3.2-48-random x86_64 GNU/Linux
~~~
## Versión de kernel \(*-r*\) 
Esta opción en cambio, solo muestra el número de versión del kernel o núcleo del sistema operativo.
~~~
uname -r
~~~
